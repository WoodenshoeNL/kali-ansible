================================================================================
                          Cloud Security Tools Reference
================================================================================

Azure CLI (az)
--------------
  Usage: az login | az ad user list | az vm list
  Description: Microsoft's command-line interface for managing Azure resources.
  OPSEC: NOT SAFE - All actions logged in Azure AD audit logs.
  Docs: https://docs.microsoft.com/en-us/cli/azure/

ROADrecon
---------
  Usage: roadrecon auth -u <user> -p <pass> | roadrecon gather | roadrecon gui
  Description: Azure AD reconnaissance tool - enumerate users, groups, apps, etc.
  OPSEC: NOT SAFE - Uses Graph API, all queries logged in Azure AD.
  GitHub: https://github.com/dirkjanm/ROADtools

ROADtx
------
  Usage: roadtx auth -u <user> -p <pass> | roadtx <command>
  Description: Azure AD authentication and token manipulation toolkit.
  OPSEC: NOT SAFE - Authentication events logged, token abuse detectable.
  GitHub: https://github.com/dirkjanm/ROADtools

ScoutSuite
----------
  Location: ~/Programs/ScoutSuite
  Usage: cd ~/Programs/ScoutSuite && source venv/bin/activate && scout azure --cli
  Description: Multi-cloud security auditing tool (AWS, Azure, GCP, etc.).
  OPSEC: NOT SAFE - API calls logged by cloud provider, read-only but visible.
  GitHub: https://github.com/nccgroup/ScoutSuite

AzureHound
----------
  Usage: azurehound -u <user> -p <pass> list --tenant <tenant> -o output.json
  Description: BloodHound data collector for Azure AD environments.
  OPSEC: NOT SAFE - Graph API enumeration logged in Azure AD.
  GitHub: https://github.com/BloodHoundAD/AzureHound

BlackCat
--------
  Location: ~/Programs/BlackCat
  Usage: cd ~/Programs/BlackCat && source venv/bin/activate && python blackcat.py
  Description: Azure AD enumeration and attack tool.
  OPSEC: NOT SAFE - Active enumeration of Azure AD, generates logs.
  GitHub: https://github.com/yakovypg/BlackCat

SeamlessPass
------------
  Location: ~/Programs/SeamlessPass
  Usage: cd ~/Programs/SeamlessPass && source venv/bin/activate && python seamlesspass.py
  Description: Tool for abusing Azure AD Seamless SSO for password spraying.
  OPSEC: NOT SAFE - Authentication attempts logged, lockout risk.
  GitHub: https://github.com/Tw1sm/SeamlessPass

EntraFalcon
-----------
  Location: ~/Programs/EntraFalcon
  Usage: cd ~/Programs/EntraFalcon && source venv/bin/activate && python entrafalcon.py
  Description: Microsoft Entra ID (Azure AD) security assessment tool.
  OPSEC: NOT SAFE - API queries logged in Entra ID audit logs.
  GitHub: https://github.com/yourname/EntraFalcon

================================================================================

Prowler
-------
  Usage: prowler aws | prowler azure --az-cli-auth | prowler m365 --az-cli-auth
  Description: Cloud security posture scanner (AWS, Azure, GCP, M365, Kubernetes, GitHub) with CIS/compliance checks.
  OPSEC: NOT SAFE - Many read-only API calls, all logged in CloudTrail / Entra ID / Activity logs.
  GitHub: https://github.com/prowler-cloud/prowler
GraphSpy
--------
  Usage: graphspy  (GUI on http://127.0.0.1:5000; -i/-p to change host/port)
  Description: Entra ID / M365 initial access and post-exploitation tool with a
    browser-based GUI (OneDrive, SharePoint, Outlook, Teams, Entra enumeration,
    phishing, token handling). Local use only - no built-in auth.
  OPSEC: NOT SAFE - Graph API / auth events logged in Entra ID audit logs.
  GitHub: https://github.com/RedByte1337/GraphSpy
AADInternals (PowerShell module)
--------------------------------
  Location: /stockpile/AADInternals (installed by the Common role)
  Usage: pwsh, Import-Module /stockpile/AADInternals/AADInternals.psd1
    (e.g. Get-AADIntTenantID, Invoke-AADIntReconAsOutsider)

  Description: Entra ID / Azure AD offensive toolkit - tenant recon, MFA method
    abuse, token manipulation, B2B backdoors.
  OPSEC: NOT SAFE - Graph API and auth events logged in Entra ID.
  GitHub: https://github.com/Gerenios/AADInternals
Az + Microsoft.Graph (PowerShell modules)
-----------------------------------------
  Usage: pwsh, Connect-AzAccount | Connect-MgGraph
  Description: Official Microsoft SDK modules for authenticated Azure RBAC and
    Graph API enumeration (Get-AzResource, Get-MgUser, role assignments).
  OPSEC: NOT SAFE - all API calls logged by Microsoft.
  Docs: https://learn.microsoft.com/powershell/azure/
TokenTacticsV2
--------------
  Usage: pwsh, Import-Module TokenTactics (e.g. Get-AzureToken -Client MicrosoftGraph)
  Description: Entra ID token toolkit - obtain/exchange/refresh tokens across
    flows (device-code phishing to FOCI resources: Graph, Outlook, SharePoint, Teams).
  OPSEC: NOT SAFE - auth events logged; conditional access may flag device-code flows.
  GitHub: https://github.com/f-bader/TokenTacticsV2
CloudFox
--------
  Usage: cloudfox az --subscriptions <id> | cloudfox az all-checks
  Description: Situational awareness and attack-path enumeration for cloud
    pentests (Azure, AWS, GCP) - principals, RBAC, role assumptions, storage.
  OPSEC: NOT SAFE - many read-only API calls, all logged.
  GitHub: https://github.com/BishopFox/cloudfox
TeamFiltration
--------------
  Usage: TeamFiltration --validate --teamfile teamfile.json
  Description: Enumerate, spray, exfiltrate and backdoor M365 / Entra ID
    accounts (Teams, OneDrive, Outlook); pairs with token tooling.
  OPSEC: NOT SAFE - spray and auth events logged; lockout risk.
  GitHub: https://github.com/Flangvik/TeamFiltration
SprayCan
--------
  Location: ~/SprayCan  (launcher: spraycan)
  Usage: spraycan  (Canvas GUI on http://127.0.0.1:8787) | spraycan --blind |
    spraycan --headless --tenant <id> --auth-mode device-code --scan 2
  Description: Local Azure / Entra ID security assessment tool - modular
    Microsoft Graph and ARM scans with a local web GUI to review output.
  OPSEC: NOT SAFE - Graph API / ARM calls logged in Entra ID and Activity logs.
  GitHub: https://github.com/DroppedSyn/SprayCan
